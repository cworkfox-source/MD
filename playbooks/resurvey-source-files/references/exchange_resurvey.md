# 重測輸入交換檔 .PTM / .BNI / .CNT / .INN

原版「資料輸出、入／重測輸入檔／產生（4 位）、（5 位）」轉出，「讀取（4 位）、（5 位）」讀入，
成果報告寫在 `neca2n.txt`。四檔為一組，**同一主檔名**才算一組
（`test_datasets/BA0338` 裡就有一個外來的 `BA0337.PAR`，依副檔名亂抓會把別段的面積接到本段）。

全部是純 ASCII、固定欄寬、CRLF 結尾的循序文字檔，無檔頭（`.PTM`／`.BNI`／`.CNT`／`.INN` 皆然）。
**權威欄位表：`file_formats/PTM.md`／`BNI.md`／`CNT.md`／`INN.md`。**

## .CNT 界址坐標（幾何來源之一）

三種已驗證方言，**用空白切詞就能全部讀出**（三者都把兩個坐標欄右靠）：

| 方言 | 版面 | 出處 |
| --- | --- | --- |
| `named` | `%-10s %11.3f %12.3f`（35 bytes） | 重建版匯出；點名可為 `n`、`n.r` 或 10 字元控制點名 |
| `field` | `%-10d %11.3f %12.3f`（35 bytes） | `lin-test/test.cnt` |
| `section` | `%5d.%d%12.3f%11.3f`（30／31 bytes，參考號不補零） | `BA0338.CNT` |

- 欄位順序永遠是 **點名、Y（縱）、X（橫）**。
- 點名 `n` ＝確定點、`n.r` ＝第 r 個參考點（`1 ≤ n ≤ 99999`、`0 ≤ r ≤ 99`），`.98` 是街廓點。
  重建宗地環時只取 `r == 0`。
- 非數字點名（如 `C326C069`）是**圖根點**，是真資料，不可靜默丟掉；
  它落在 `數字.參考號` 命名空間之外，另存一份 `點名 -> 坐標`。
- 讀入原版時界址點坐標來源會被自動設為「套圖數化」，且**點號與既有點重複時原坐標會遺失**。

## .BNI 地號界址（點號序列）

每錄最多 11 組「圓弧碼 A1 ＋ 界址點號 I4/I5」，key 是**原地號**。

```
[0:4] 原地號母號  [4:8] 原地號子號  [8:12] 原段號
[12:15] 序號      [15:17] 圓弧      [17:19] 地中地   [19:23] 界址點數
[23:] 11 組（A1 圓弧碼 + I4 或 I5 點號）
```

- **4 位版每組 5 bytes、5 位版每組 6 bytes**。判別方式：以該錄宣告的「界址點數」
  對 I4／I5 兩種切法各解一次，取解出點數最接近期望值者（`BA0338.BNI` 實測為 5 位版）。
- 續錄依 **序號欄由小到大** 接續（不是物理順序）。
- 圓弧記號實際是點號的**後綴** `+`／`-`（手冊寫成前置欄位），固定欄寬切下來會落在
  下一組的 A1 欄，正好標記弧中點。**不要用空白切詞**，`2094+` 會整個 token 解析失敗。
- 手冊附錄的格式表標題把 `.BNI` 誤植為 `.BNP`，欄位配置與複丈ⅠⅡ版 `.BNP` 相同；
  檔名一律以 `.BNI` 為準。

## .PTM 宗地屬性（**沒有任何坐標**）

資料錄 51 bytes：

```
[0:4] 原地號母  [4:8] 原地號子  [8:12] 原段號  [12:16] 新段號
[16:20] 界址點數  [20:22] 有無地中地  [22:23] 空白  [23:25] 地目
[25:36] 原登記面積 F11.6 —— 單位**公頃**（×10000 得 m²）
[36:38] 等則  [38:41] 調查情形  [41:43] 公私有  [43:45] 使用情形
[45:47] 建物登記  [47:51] 所有權人數
```

- 空欄很常見（`BA0338.PTM` 的界址點數／地中地整欄空白），空白要當 NULL 不是 0。
- 代碼欄的意義查 `file_formats/_codes.md`。
- 它只給屬性；圖形一律來自 `.CNT` ＋ `.BNI`。

## .INN 新舊地號對照

```
[0:4] 原地號母  [4:5] 空白  [5:9] 原地號子  [9:13] 原段號
[13:14] 空白    [14:18] 新地號母  [18:22] 新地號子
```

手冊格式表把第 6、7 欄的欄名也寫成「原地號母號／子號」，依用途研判為**新**地號誤植；
解析時請用實際資料驗證（同一列前後兩組地號通常不同）。

## 讀進來之後要驗什麼

- 每宗地都要成環：`BA0338`（1,323 宗地）以 `.CNT`＋`.BNI` 重建**全部成環、0 筆失敗**。
- `.CNT` 點名閉包：`.BNI` 用到的每個點號都要能在 `.CNT` 查到坐標。
- **不要拿環面積去對 `.PTM` 的原登記面積**當作正確性指標。`.CNT`／`.BNI` 也是原版
  用來匯出「現況成果」的格式（`BA0338.CNT` 逐點等於該段 `.D14`，最大差 0.5 mm），
  現況幾何 vs 重測前登記面積本來就不同（實測只有 69% 落在 0.1% 內）。
  要驗面積請對該段自己的 `.D11 AREA_NEW`。
