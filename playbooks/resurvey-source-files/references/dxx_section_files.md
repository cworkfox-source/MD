# 段目錄原始檔 .D10~.D2D / .D25 / .NTX

段目錄以段代碼 `$$####` 命名（`$$`＝兩碼事務所代碼，`####`＝四碼段代碼，如 `BA0002`），
檔案主檔名同段代碼。**欄位表的權威來源是 `file_formats/D1x.md`／`D2x.md`**；
本文是讀法與陷阱。

## 1. 這些檔就是 dBASE III

`.D23`（ASCII）與 `.D25`（自訂二進位）以外的 `.D1x`／`.D2x` 都是標準 dBASE III `.dbf`，
可用任何 dbf 函式庫讀，也可以自己讀（`scripts/read_resurvey.py` 的 `read_dbf()` 就是）。

```
byte 0      版本，0x03 = dBase III
byte 1–3    最後更新日期 —— ⚠ 本系統 year byte 恆為 0x7E，不合 年-1900 慣例，
            不可用來判斷資料異動時間，也不可拿來辨識檔案
byte 4–7    資料筆數（LE uint32）
byte 8–9    檔頭長度（LE uint16）
byte 10–11  每筆長度（LE uint16）
byte 32 起  欄位描述，每欄 32 bytes：名稱[0:11] NUL 結尾／型態[11]／長度[16]／小數[17]
            直到遇到 0x0D 結束
資料區      每筆固定長度，第 0 byte 是刪除旗標：空白＝正常、'*'＝已刪除**必須略過**
```

- 辨識 dbf 用「`檔頭長度 + 筆數 × 每筆長度` ＝ 檔案大小（可多 1 byte 的 `0x1A`）」，
  不要用檔頭日期。既有樣本有「無檔尾」與「單一 `0x1A`」兩種變體，兩種都要接受。
- 欄位值一律**固定起始位置＋長度**擷取，不要用空白切字串。
- N 欄右靠補空白；空白視為 NULL，不是 0。C 欄以 CP950 解碼後 strip。
  L 欄 `T`/`Y` 為真、`F`/`N` 為偽。
- `.Bxx`（`.B11`、`.B13`、`.B2C`…）是對應 `.Dxx` 的備份副本，schema 相同；
  不要把它當成獨立資料源，也不要拿它跟本體做「差異分析」而誤判為異動。

## 2. 一段有哪些檔

| 檔 | 內容 | 讀取重點 |
| --- | --- | --- |
| `.D10` | 段基本管理（段代碼、日期、比例尺） | 1 筆記錄。`SCALE`／`OLDSCALE` 可能整欄空白（BA0002、DD2138 就是），比例尺要能手動補 |
| `.D11` | 宗地屬性 36 欄 143 bytes | `AREA_OLD`／`AREA_NEW`／`AREA_DIG` 單位**公頃**；第 21 欄以後語意為推測 |
| `.D12` | 地中地關係 | 每列一組「父地 → 一筆地中地」；父地面積必須扣掉地中地 |
| `.D13` | 地號界址（點號序列） | 每錄 8 點，**跨錄接續**，見下節 |
| `.D14` | 界址坐標 | `COT_REF==0` 才是確定點；坐標 N16.8／N15.8 |
| `.D15` | 分割合併關係 | BA0002 樣本為空表 |
| `.D20` | 私有圖根補點（點名 `Q` 開頭） | BA0002 樣本為空表 |
| `.D21` | 經界線（起點／弧中點／終點＋左右宗地＋查註） | `LIN_MID=0` 為直線；與 D13 是同一批邊的兩種索引 |
| `.D22` | 圖幅號索引 | BA0002 樣本為空表 |
| `.D23` | 區段界 | ASCII，`[A] NUM Y X [MODE]`，空白列分隔不同線串 |
| `.D25` | 測量資料記錄 | **非 dBASE**，見第 5 節 |
| `.D29` | 參考線段（0~9 層） | 端點欄是**文字型**，可直接存 `100.23` 與控制點名如 `C326C069` |
| `.D2B`/`.D2C`/`.D2D` | 舊地籍圖的地號界址／坐標／經界線 | 欄位配置與 D13／D14／D21 幾乎相同，key 為**原地號** |
| `.D26`/`.D27`/`.D28`/`.D2A`/`.D2F` | 編圖檔 | 僅知命名規則，repo 內無樣本 |

## 3. D13 + D14 重建宗地環

```python
# 1) 序列：同 (O_SECTION, O_PARCEL, O_PARCEL_E) 的多錄，依**檔案物理順序**接續
#    D13 沒有序號欄；某錄的 COORD_n = 0 代表該宗地已列完，其後補零全部忽略
# 2) 弧中點：同一組的 MIDARC_n = T
# 3) 坐標：以 D14 的 COT_NUMBER 建索引，只收 COT_REF == 0
# 4) 清理：連續重複點只留一個；首尾同點去尾
# 5) 拒絕：點數 < 3 或有點號查不到坐標 → 不產生 polygon
```

實例（BA0002.D13 段 755、母 365、子 2，共 17 點跨 3 錄）：

```
錄1  6857 6941 6942 6943 6957 6956 6955 6954
錄2  6953 7125 6972 6971 6969 6966 6965 6964
錄3  6932 0 0 0 0 0 0 0        ← 補零＝結束
```

## 4. 面積驗證（讀對了沒有的唯一硬指標）

- 直線邊 shoelace；`MIDARC_n = T` 的三點以解析式真弧取代兩段弦（ADR-075）。
  只算弦會低估：BA0762 舊圖弧宗地最大誤差 120.91 m²，改真弧後全部落在 0.01 m² 內。
- **地中地**：父地淨面積 ＝ 外環面積 − 各直屬地中地外環面積。
  BA0002 的 760-73-9 外環 3748.758 m²、23 筆地中地扣掉後 2280.976 m²，
  D11 `AREA_NEW` 為 2280.980 m²（差 0.004 m²）。不扣就是差 1467 m² 的離群值。
- 比對 `.D11` 的 `AREA_NEW`（公頃）：`polygon 面積(m²) ≈ AREA_NEW × 10000`，
  差 ≤ 2 m² 才視為可信。BA0002 全段 1,209 筆有對照者 100% 通過。
- `AREA_DIG` 是原版自己算的舊圖數化面積（只有執行過「讀取舊地籍圖」的段才有值），
  可拿來交叉驗證 D2B 環；BA0002 3,498 筆中位誤差 0.0037%。

## 5. .D25：唯一不是 dBASE 的段內資料檔

```
每筆 79 bytes，記錄間無分隔；檔尾另有 32 bytes 的 NULLTAB 哨兵
檔案大小 = 79 × 筆數 + 32
  [4:8]    LE uint32 遞增序號／時間戳（[8:12] 與其恆相同）
  [32:39]  點名1（ASCII, NUL 結尾）   [41:48] 點名2   [50:57] 點名3
  [60:68]  double —— 樣本只有 0.0 與 π 兩種離散值，語意未確認
  [69:77]  double —— 研判為觀測距離（公尺）
  [77:79]  恆為 ',*'
```

點名1/2/3 對應手冊的「測站點／標定點／觀測點」何者**尚未確認**，不要在程式裡寫死語意。
要確認語意的正規做法：對同段執行原版「產生測量文字檔」得到 `.MAC`，逐筆比對。

## 6. .NTX / .MTX：預設不要碰

- 索引檔，1024 byte page 的 B-tree；手冊註明**可刪除**（系統可重建）。
- 讀取結構已用 BA0001／BA0002 實檔驗證（header 的 key expression 可直接讀出，
  例如 `COORDS.NTX` 是 `STR(COT_NUMBER,5)+STR(COT_REF,2)`），
  但**原版增量寫入行為未驗證，禁止仿作寫入**。
- 資料一律從 `.Dxx` 本體讀。需要索引只是為了加速時，自己在記憶體建 dict 就好。
