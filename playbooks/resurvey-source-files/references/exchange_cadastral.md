# 複丈系統交換檔 .PAR / .BNP / .COA / .RCO

同一組副檔名有**兩種版面**：複丈ⅠⅡ版與整合版。
原版只有**整合版可讀入**（ⅠⅡ版僅供輸出），成果報告寫在 `ned12nec.txt`。
本 repo 的樣本（`BA0338`／`BA0762`／`DD2138`）**全部是整合版**，ⅠⅡ版無樣本、僅依手冊實作並標示未驗證。

**權威欄位表：`file_formats/PAR.md`／`BNP.md`／`COA.md`／`RCO.md`。**
圖解數化成果管理系統的 `.PUN`／`.BUN`／`.CUN` 分別與整合版 `.PAR`／`.BNP`／`.COA` 同格式。

## 版本判別（先做這一步）

**第一列是不是標題錄**：整合版的第一列是 `A2 事務所代碼 + 數字…`（regex `^[A-Za-z]{2}\d`）。
有標題錄 → 整合版，跳過該列再讀資料錄；沒有 → 走 ⅠⅡ版後備。

| 項目 | ⅠⅡ版 | 整合版 |
| --- | --- | --- |
| `.PAR` 面積單位 | 公頃（F10.6） | **平方公尺**（F10.2） |
| `.PAR` 地目 | I2 | A1 |
| `.BNP` 地號空間 | **原**地號（母/子/原段號） | **新**地號（母/子） |
| `.BNP` 點號欄寬 | I4 | **I5** |
| `.COA` 資料錄點號欄 | 無（依記錄順序推定） | 有（I5） |
| `.COA` 坐標精度 | F12.3／F11.3 | F16.8／F15.8 |

## .COA 界址坐標（整合版，資料錄固定 38 bytes）

```
[0:5]   I5   點號
[5:6]   A1   確定否（樣本見 '1' 與空白兩種）
[6:22]  F16.8 Y 坐標（縱）
[22:37] F15.8 X 坐標（橫）
[37:38] A1   界標種類
```

標題錄實測 23 bytes（`A2 + I4 新段號 + I5 最大點號 + I2 坐標來源 + I5 坐標系統 + I5 資料錄總數`），
與手冊所列七欄 I5 不完全一致 → **只跳過標題錄，不要依賴它的欄寬**。
坐標為 `(0, 0)` 的列視為無效，略過。

## .BNP 地號界址（整合版，key 是新地號）

```
[0:4]  I4  新地號母號
[4:8]  I4  新地號子號
[8:11] I3  序號
[11:15] I4 界址點數
[15:]  11 組（A1 圓弧碼 + I5 點號），每組 6 bytes
```

- 續錄依**序號**由小到大接續（`DD2138` 有 24 點分 3 錄的實例）。
- 圓弧是點號的**後綴** `+`／`-`，固定欄寬切下來落在下一組的 A1 欄：

  ```
  09940000  1   5  2102  2103  2094+ 3039  2093
  ```

  ＝從 2094 起、經弧中點 3039、連到 2093。按手冊的「前置圓弧碼」解讀會把 `2094+`
  整個 token 丟掉：BA0762 面積符合率 91.9%→99.0%、p95 誤差 16.29%→0.12%。
- **弧中點被計入「界址點數」，它是真實界址點**，保留為頂點；
  面積用相鄰三點的解析式真弧，不要用渲染折線插值（ADR-075）。

## .PAR 宗地屬性（整合版，資料錄 63 bytes）

```
[0:4] 原母  [4:8] 原子  [8:12] 原段號
[12:22] 原登記面積（**平方公尺**）
[22:26] 新母  [26:30] 新子
[30:40] 新面積（**平方公尺**）
[40:41] 地目 A1  [41:43] 等則 I2
[43:52] 視中心 Y  [52:60] 視中心 X  [60:63] 圖幅號
```

標題錄實測 22 bytes：`A2 事務所 + I4 新段號 + I5 宗地總筆數 + I3 年 + I2 月 + I2 日 + I4 最大地號`
（BA0338 ＝ 1313 筆／113 年 11 月 8 日／最大地號 1323）。

### ⚠ join key：接 .BNP 要用新地號

整合版 `.BNP` 以**新地號**編 key，所以要取 `.PAR` 的 `[22:26]/[26:30]`。
用 `[0:4]/[4:8]`（原地號）會完全接不起來——BA0338 實測原 13-1 對新 238-0。
反過來，舊圖宗地環（`.D2B`／`.BNI`）是**原地號**空間：BA0762 的 738 筆 D2B 宗地
命中原地號 714 筆、命中新地號 **0 筆**。兩個地號空間必須分開保存。

## .RCO 參考坐標（整合版）

```
[0:5] I5 點號（所屬確定點）  [5:7] I2 參考點編號 1~99
[7:18] F11.3 Y  [18:28] F10.3 X  [28:29] A1 界標種類
```

ⅠⅡ版坐標欄各多 1 位（F12.3／F11.3）且無界標種類欄。
只有標題錄、沒有資料錄是合法的（`DD2138.RCO` 全檔 13 bytes ＝ 0 筆）。

## 讀進來之後要驗什麼

以 `.COA` 的點 ＋ `.BNP` 的序列重建環，再對 `.PAR` 的**新面積**（平方公尺，新地號 key）：

| 樣本 | 宗地 | 成環 | 面積在 2 m² 或 0.1% 內 |
| --- | ---: | ---: | --- |
| `BA0762` | 714 | 714 | **714 / 714** |
| `DD2138` | 1,359 | 1,359 | **1,359 / 1,359** |

殘差普遍是 0.005 m² 等級（F10.2 的量化）。若只有含弧宗地不合 → 圓弧後綴讀錯；
若整批差 10000 倍 → 誤用了ⅠⅡ版的公頃假設；若幾乎全部接不到面積 → join key 取成原地號。

`.COA` 與 `.CNT` 一樣**同時是原版匯出現況成果的格式**：本 repo 三份 `.COA` 逐點等於
該段自己的 `.D14`（`DD2138` 最大差 0.0 mm、`BA0762` 0.5 mm）。
因此只有在目錄同時沒有 `.D14`、`.D2C`、`.D2B` 時，才可以把交換檔當舊圖匯入（ADR-040）。
