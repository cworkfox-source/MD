# 測量輸入檔 .MAC / .CTL（與 .CEN / .CT2 / .RAW / .LIN / .CN1~.CN3）

**權威欄位表：`file_formats/MAC.md`／`CTL.md`／`RAW.md`／`LIN.md`／`CEN.md`／`CN1.md`~`CN3.md`。**

## .MAC 測量資料文字檔

外業觀測的文字輸入檔，供「批次計算」執行光線法與直線截點；也是「產生測量文字檔」
把 `.D25` 轉出的格式。ASCII，由前導命令列開頭的計算區塊組成。

```
LS                                  ← 光線法區塊
測站點  後視（標定）點
觀測點[(註記)]  右旋角  平距           ← 無天頂距
觀測點[(註記)]  右旋角  天頂距  斜距    ← 有天頂距
...
LB                                  ← 直線截點區塊
已知點一  已知點二
第一段距離  存檔的點號
第二段距離  存檔的點號
最後段距離                            ← 最後一段只有距離、沒有點號
```

讀取規則：

- 各欄以**一個以上空白**隔開（實檔也有以逗號分隔者，先把逗號換成空白再切）。
- 點號／點名直接寫，**不需前導碼 `*`**。
- **角度是「度.分秒」**：`12.2345` ＝ 12°23′45″。原版既有檔可能省略尾端 0
  （`293.191` ＝ `293.1910` ＝ 293°19′10″），讀取時要**向右補零到 4 位**再換算。
  換算：`度 + 分/60 + 秒/3600`（`scripts/read_resurvey.py` 的 `dms_to_degrees()`）。
- 觀測點可帶括號註記，如 `5.5(502)`、`100(3+)`＝點號 100、經界物代碼 `3+`（牆壁‧內）。
  註記不含空格或逗號，見 `file_formats/_codes.md` 的經界物代碼表。
- 觀測點點名 `Q` 開頭者為私有補點，原版會建到 `.D20`。
- **同一檔不得重複 `LS`**：15 份 BA0528 實檔每檔最多一個 `LS`；原版在第二個 `LS` 後的
  測站列會報 `MACRO` 錯誤。要換測站是在同一個 `LS` 區塊內插入新的兩欄「測站 後視」列。
  `LB` 與 `LS` 混合、或重複 `LB` 尚未動態驗證，不要據此推論。
- 檔名不限 `$$####.MAC`；讀取時任意檔名、任意目錄都可以（實檔也有 `.mac` 小寫）。

## .CTL 圖根點坐標

控制測量處理系統與本系統之間的圖根點交換檔，主檔名慣例為 `$$0000.CTL`。

```
第一錄（標題）：A2 事務所代碼 + A1 版標記(如 B=複丈版) + A7 填零；實檔也見
                「檔名字串」型標題（BA0113.LST、DDD100000000）
資料錄：A8 點號（左靠）+ F11.3 縱坐標 Y + F12.3 橫坐標 X
```

⚠ 實檔欄位有**貼死**也有**以空白隔開**，固定切法會切壞其中一種：

| 樣本 | 樣子 |
| --- | --- |
| `DD2138.CTL` | `BQ002   2583570.092176487.151  ` ← Y 與 X 貼在一起 |
| `BA0000.CTL` | `B028     2672841.618 214779.525` ← 中間有空白 |
| `BA0113.CTL` | `BL030    2669841.355 217892.249    0.000` ← 還多一欄 |

穩健讀法：**先用空白切詞取前三個 token（點名／Y／X），失敗才退回固定欄寬 `[0:8]/[8:19]/[19:31]`**；
多出來的第 4 欄不要解讀。標題錄用「解不出兩個浮點數就跳過」自然排除。
實測：`BA0000` 56 點、`BA0113` 108 點、`DD2138` 197 點、`GW9000` 306 點。

## 其餘測量相關檔

| 副檔名 | 內容 | 狀態 |
| --- | --- | --- |
| `.CEN` | 中心樁坐標輸入/輸出 | 手冊未載格式；與 `.CTL` 一起由「控制測量輸入檔／讀取」讀入 |
| `.CT2` | 私有補點輸出 | 手冊未載格式 |
| `.RAW` | 外業自動化觀測資料 | 手冊未載格式；與 `.MAC` 同為「批次計算」的輸入 |
| `.LIN` | 外業自動化連線資料 | 手冊未載格式。本專案另定義了**點名版 `.LIN`** 匯出（來源是 `.D29`），弧中點寫在 `-ARC.LIN`，見 `file_formats/LIN.md` |
| `.CN1`/`.CN2`/`.CN3` | 街廓坐標／街廓連線／中心樁連線 | 讀入行為可知；連線資料會存到 `.D29` 的**第 9 層**（`LIN_MODE=9`） |

格式未載明者（`format_spec: none`）**不要嘗試直接解析或寫入**，改走原版「資料輸出、入」
轉成交換格式再讀。
