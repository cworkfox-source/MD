# .ERR 重測成果檢核報表檔

## 用途

「資料整理／重測成果檢核」執行後產生之檢核報表，供成果繳交前判斷資料是否正確。

## 內容項目（手冊有載，報表版面未載）

檔案內容區分為下列大項：

### 1. 經界線檢查

- 三點圓弧之圓弧中距小於 1 mm 者（應改成二條直線）。
- 三點圓弧圓心角超過 180 度（半圓）且圓弧中點偏離者（面積計算盲點，圓弧中點不得偏移）。
- 圓弧三點之中點偏離圓弧中心線超過 10%者（警告）。
- 「…… 地號 …… 與 …… 交錯」：宗地地號中線段交錯（注意：直線與圓弧連續且同時交錯時檢核可能誤通過）。

### 2. 整段面積檢查

回報：
1. 各筆宗地實際新面積總和
2. 各筆宗地登記新面積總和（四捨五入至登記單位後累加）
3. 段外圍面積（程式自動判斷之整段外圍）
4. 自由閉合區面積（漏列地區或地號界址填列跳號；趨近 0.0 表點剛好在線段上而漏列）
5. 「xxx 線段僅被 xxx 地號用到」

判讀規則：(1) 與 (3) 應相等，最多差 0.01 ㎡；(1) 與 (2) 之差不應超過 1 ㎡；不合理之 (3) 與全部 (4)(5) 均屬錯誤。

### 3. 調查情形欄與經界線糾紛設定檢核

調查情形代碼 5、6 之宗地，其相對應經界線是否設定糾紛。

### 4. 宗地資料與地號界址

有宗地資料而無地號界址之地號。

### 5. 新地號檢核

未建新地號之宗地。
