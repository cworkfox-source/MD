# .CN1 中心樁連線資料檔

## 用途

都市計劃樁清理補建系統產生之**中心樁連線資料**，與 .CN2（街廓連線）、.CN3（街廓坐標）成組轉入重測系統。

## 已知行為（讀入規則）

- 「資料輸出、入／讀街廓資料」：選取 .CN1、.CN2、.CN3 任一檔即可整組讀入。
- 讀入之**街廓點存為點號 `.98` 之參考點**。
- 讀入之街廓連線存至**參考線第 9 層**。
- BA0528 `111CS.CN1` 實測為 504 組中心樁點名成對連線，逐筆對應 D29
  `LIN_MODE=8` 的 504 條線；此「CN1 → 第 8 層」是實檔對穿證據，手冊未明載。
- 「資料輸出、入／刪街廓資料」：刪除 `.98` 參考點及其連線資料。

## 內容格式

BA0528 實檔每筆為兩個中心樁點名；其餘變體仍需向都市計畫樁清理補建系統文件查證。
