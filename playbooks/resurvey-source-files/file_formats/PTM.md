# .PTM 宗地資料檔（重測系統輸入檔）

> 本專案讀取位置：`legacy_area.parse_ptm_areas()`（無條件讀取）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

重測系統之宗地資料交換檔，與 .BNI（地號界址）、.CNT（界址坐標）、.INN（新舊地號對照）合為一組「重測輸入檔」。
亦為舊版重測資料處理系統之輸出/入檔格式。

## 內容格式（手冊有載）

資料記錄（無標題記錄之記載）：

| 順序 | 資料名稱 | 格式 | 說明 |
| ---: | --- | --- | --- |
| 1 | 原地號母號 | I4 | |
| 2 | 原地號子號 | I4 | |
| 3 | 原段號 | I4 | |
| 4 | 新段號 | I4 | |
| 5 | 界址點數 | I4 | |
| 6 | 有無地中地 | I2 | |
| 7 | 空白 | A1 | |
| 8 | 地目 | I2 | |
| 9 | 原登記面積 | F11.6 | 單位為公頃 |
| 10 | 等則 | I2 | |
| 11 | 調查情形 | I3 | 代碼見 [_codes.md](_codes.md) |
| 12 | 公私有 | I2 | 代碼見 [_codes.md](_codes.md) |
| 13 | 使用情形 | I2 | 代碼見 [_codes.md](_codes.md) |
| 14 | 建物登記 | I2 | 代碼見 [_codes.md](_codes.md) |
| 15 | 所有權人數 | I4 | |

## 產生/讀取功能

- 「資料輸出、入／重測輸入檔／產生（4 位）、產生（5 位）」：轉出 `$$####.CNT`、`$$####.BNI`、`$$####.PTM`（覆蓋既有檔）。點號超過五位數需求時選擇 4 位或 5 位轉出。
- 「資料輸出、入／重測輸入檔／讀取（4 位）、讀取（5 位）」：讀取目錄下重測輸入檔；成果報告寫入 `neca2n.txt`。
- 「資料輸出、入／讀取 .PTM」：單獨將外部宗地資料檔全部轉入（手冊註明此功能在以後版本中可能關閉）。
- 「資料輸出、入／舊地籍圖資料／讀取（4 位）、讀取（5 位）」：將 .PTM/.BNI/.CNT 以舊圖模式讀入（存入 .D2B/.D2C/.D2D 舊地籍圖資料層）。

## 重建版實測（ADR-041）

`test_datasets/BA0338/BA0338.PTM`、`BA0762/PTM-0700.PTM` 逐位元組驗證，資料錄 51 bytes：

| 位元組 | 欄位 |
| --- | --- |
| `[0:4]` `[4:8]` `[8:12]` | 原地號母／子／原段號 |
| `[12:16]` | 新段號 |
| `[16:20]` `[20:22]` `[22:23]` | 界址點數／有無地中地／空白 |
| `[23:25]` | 地目 |
| `[25:36]` | 原登記面積（**公頃**，F11.6；換算平方公尺須 ×10000） |
| `[36:38]` `[38:41]` `[41:43]` `[43:45]` `[45:47]` `[47:51]` | 等則／調查情形／公私有／使用情形／建物登記／所有權人數 |

### 本檔沒有任何坐標

.PTM 為純屬性檔，**不含界址點坐標，也不含點號序列**，因此無法單獨產生圖形；
舊圖幾何一律來自 .CNT/.COA（點）與 .BNI/.BNP（環），見 [BNP.md](BNP.md)。
重建版只取其「原登記面積」供舊圖宗地的面積比對，且以 .PAR 為優先來源
（.PAR 直接記錄平方公尺並另帶新地號空間）。BA0762 的 `PTM-0700.PTM` 補足了
.PAR 未涵蓋的宗地，使該段 738 筆舊圖宗地全數取得登記面積。
