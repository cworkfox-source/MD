# .COA 界址坐標檔（複丈系統輸入檔）

> 本專案讀取位置：`legacy_import.parse_coa()`（僅當目錄無 D14／D2C／D2B 且無 .CNT 時觸發）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

複丈系統之界址（確定點）坐標交換檔。**同一副檔名有兩種版本格式**。
圖解地籍圖數值化成果管理系統之 .CUN 與整合版 .COA 格式相同。

## 格式一：複丈系統ⅠⅡ版（手冊有載）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 最大記錄數 | I5 |
| 最大點號 | I5 |

### 資料記錄（其他錄）

| 資料名稱 | 格式 |
| --- | --- |
| 確定否 | I2 |
| Y 坐標 | F12.3 |
| X 坐標 | F11.3 |

**注意**：ⅠⅡ版資料記錄**無點號欄**；推測點號即為記錄順序（第 n 筆資料錄＝點號 n，配合標題錄之最大點號），手冊未明文說明，實作時請以實際資料驗證。

## 格式二：複丈系統整合版（手冊有載）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 最大點號 | I5 |
| 坐標資料來源 | I5 |
| 坐標系統總類 | I5 |
| 比例尺 | I5 |
| 資料錄總數 | I5 |

### 資料記錄（其他錄）

| 資料名稱 | 格式 |
| --- | --- |
| 點號 | I5 |
| 確定否 | A1 |
| Y 坐標 | F16.8 |
| X 坐標 | F15.8 |
| 界標種類 | A1 |

## 版本差異速記

| 項目 | ⅠⅡ版 | 整合版 |
| --- | --- | --- |
| 資料錄含點號 | 無（依序推定） | 有（I5） |
| 坐標精度 | F12.3 / F11.3 | F16.8 / F15.8 |
| 界標種類欄 | 無 | 有（A1） |
| 標題錄 | 4 欄 | 7 欄（含坐標來源、坐標系統、比例尺） |

## 重建版實測（ADR-040）

`test_datasets/DD2138.COA`（4,113 筆）、`BA0762.COA`（1,410 筆）、`BA0338.COA`
逐位元組驗證，**皆為整合版**，資料錄固定 38 bytes 且與手冊欄寬相符：

| 位元組 | 寬度 | 欄位 |
| --- | --- | --- |
| `[0:5]` | I5 | 點號 |
| `[5:6]` | A1 | 確定否（樣本見 `1` 與空白兩種） |
| `[6:22]` | F16.8 | Y 坐標 |
| `[22:37]` | F15.8 | X 坐標 |
| `[37:38]` | A1 | 界標種類 |

標題錄實測為 `A2 事務所 + I4 新段號 + I5 最大點號 + I2 坐標來源 + I5 坐標系統 + I5 資料錄總數`
（23 bytes），與手冊所列七欄 I5 的寬度不完全一致；重建版只跳過標題錄，不依賴其欄寬。

### ⚠ 這些樣本是「現況」匯出檔，不是舊圖

repo 內三份 .COA 逐點比對後，**全部等於該段自己的 D14 現況點**
（DD2138 最大差 0.0 mm；BA0762 0.5 mm＝F16.8 寫入後仍受來源 mm 精度限制）。
`.COA`/`.CNT` 是**傳輸格式**：內容是舊圖或現況，取決於當初由哪個功能產生
（「產生整合版輸入檔」匯出現況；「舊地籍圖資料／讀取」才把外來檔宣告為舊圖）。
因此重建版只在目錄同時沒有 D14、D2C、D2B 時才把交換檔當舊圖匯入。

複丈ⅠⅡ版（無點號欄、F12.3/F11.3）在 repo 內**無樣本**，僅依手冊實作為後備並標示未驗證。
