# .PAR 宗地資料檔（複丈系統輸入檔）

> 本專案讀取位置：`legacy_area.parse_par_areas()`（無條件讀取，覆蓋 .PTM）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

複丈系統之宗地資料交換檔，與 .BNP/.COA/.RCO 合為一組。**同一副檔名有兩種版本格式**（ⅠⅡ版／整合版），依檔案格式區分。
圖解地籍圖數值化成果管理系統之 .PUN 與整合版 .PAR 格式相同。

## 產生/讀取功能

- 「資料檔輸出、入／複丈系統輸入檔／產生 I、II 版輸入檔、產生整合版輸入檔」：轉出 .PAR/.BNP/.COA/.RCO（覆蓋既有檔）。
- 「資料輸出、入／複丈系統輸入檔／讀取整合版輸入檔」：讀入整合版（既有地號界址、界址坐標、宗地資料將被覆蓋）；成果報告寫入 `ned12nec.txt`。**僅整合版可讀入**，ⅠⅡ版僅供輸出。

## 重建版實測（ADR-041）

`test_datasets/BA0338.PAR`、`DD2138.PAR`、`BA0762.PAR` 逐位元組驗證，**皆為整合版**，
資料錄 63 bytes，欄位位置與手冊相符：

| 位元組 | 欄位 | 備註 |
| --- | --- | --- |
| `[0:4]` `[4:8]` `[8:12]` | 原地號母／子／原段號 | 舊圖宗地的 join key |
| `[12:22]` | 原登記面積 | 整合版為**平方公尺** |
| `[22:26]` `[26:30]` | 新地號母／子 | |
| `[30:40]` | 新面積 | 整合版為**平方公尺** |
| `[40:41]` `[41:43]` | 地目 A1／等則 I2 | |
| `[43:52]` `[52:60]` | 視中心 Y／X | |
| `[60:63]` | 圖幅號 | |

標題錄實測 22 bytes：`A2 事務所 + I4 新段號 + I5 宗地總筆數 + I3 年 + I2 月 + I2 日 + I4 最大地號`
（BA0338＝1313 筆／113 年 11 月 8 日／最大地號 1323）。

### ⚠ join key：舊圖配原地號，.BNP 配新地號

舊圖宗地環（.D2B 的 `O_SECTION/O_PARCEL/O_PARCEL_E`、.BNI 的原段號/母/子）以**原地號**編 key，
整合版 .BNP 則以**新地號**編 key。BA0762 實測：738 筆 D2B 宗地中 **714 筆命中原地號**、
命中新地號 **0 筆**。BA0338 更直接證明兩者不同（原 13-1 對新 238-0）。
兩個地號空間必須分開保存，合併會取到錯誤面積。

（`BNP_COA_PAR_讀取說明與Agent_Skill.md` 的範例程式以 `line[0:4]+line[4:8]`＝原地號作為 PAR 的 key
去接整合版 BNP 的新地號，該處無法對接。）

ⅠⅡ版兩欄位置相同但單位為**公頃**；repo 內無樣本，重建版依手冊換算但標示未驗證。

## 無 D11 時的換段 PTM 對應（ADR-111）

換段輸出遇到 ADR-112 的純 `.COA＋.BNP＋.PAR` 工作段時，只使用該 view 已選定的同組整合版 PAR：`[22:30]` 新地號成為 PTM 地號，`[30:40]` 新面積由平方公尺除以 10,000 輸出為 F11.6 公頃，`[40:43]` 供地目／等則。整合版 PAR 不含調查情形、公私有、使用情形、建物登記與所有權人數，對應 PTM 欄位以 0 表示無資料。有 D11 時仍優先 D11，不改變原版逐位元組輸出。
