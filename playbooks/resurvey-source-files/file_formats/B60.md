# .B60 交會法計算結果報表

## 用途

「界址計算／交會法」（兩已知點各觀測右旋水平角前方交會）之計算結果報表。

## 已知行為

- 主檔名為系統日期之年月日。
- 角度以小數點區分度分秒（12 度 23 分 45 秒 → `12.2345`）；僅限右旋度盤經緯儀。
