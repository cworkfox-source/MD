# .CNT 界址坐標檔（重測系統輸入檔）

> 本專案讀取位置：`legacy_import.parse_cnt()`（僅當目錄無 D14／D2C／D2B 時觸發）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

重測系統之界址坐標交換檔；亦為套圖數化成果（坐標讀取儀）轉入系統之標準管道。

## 已驗證的三種版面

手冊記載的 `F6.1/F12.3/F11.3` 無法完整描述實體樣本（例如兩位參考號 `.55`、`.98`）。
重建版因此以樣本逐位元組結果為準，並明確區分三種方言：

| 方言 | 寫入格式（不含 CRLF） | 用途／證據 |
| --- | --- | --- |
| `named` | `%-10s %11.3f %12.3f`（35 bytes） | 重建版匯出格式；點名可為 `n`、`n.r` 或最長 10 字元控制點名 |
| `field` | `%-10d %11.3f %12.3f`（35 bytes） | `lin-test/test.cnt`；16,365 筆，與 D14 同序且坐標全數相符 |
| `section` | `%5d.%d%12.3f%11.3f`（變長） | `BA0338/BA0338.CNT`；參考號不補零，記錄依參考號位數為 30／31 bytes |

三者皆為純 ASCII、每筆以 `CRLF` 結束、無檔頭。`named`／`field` 的欄位是點名、N（Y）
坐標、E（X）坐標；`section` 的坐標欄順序同為 Y、X，但欄寬分別為 12、11。

### 重建版 `named` 點名規則

- 確定點：`n`，例如 `1`（不寫 `1.0`）。
- 參考點：`n.r`，例如 `1.1`、`1.98`；`r` 不補零。
- D14 值域為 `1 <= n <= 99999`、`0 <= r <= 99`。
- 點名超過 10 字元或坐標四捨五入至三位後超出欄寬時必須報錯，不得截斷或改寬。

`named` 在資料全為確定點時與 `field` 位元組相同。是否能由原版 `READCNT` 讀取含小數點的
點名欄仍待動態驗證；目前是重建版明確定義的交換格式。

## 產生/讀取功能

- 「資料輸出、入／讀取 .CNT」：將外部界址坐標轉入。
  - 讀入之界址點坐標來源自動設定為**套圖數化**。
  - 界址點號與系統既有點號重複時，原坐標值會遺失，需特別注意。
  - 異動資料產生至 **.B11** 報表檔。
- 「資料輸出、入／重測輸入檔／產生（4 位）、（5 位）」：與 .BNI/.PTM 一併轉出。
- 「報表、輸出／協助指界檔」：`.2` 以上參考點輸出至 `$$####.CNT`。
- 「資料輸出、入／舊地籍圖資料／讀取」：以舊圖模式讀入（存入 .D2C 舊地籍圖界址坐標檔）。

## 重建版實作

`nec_rebuild.cnt_export` 提供三方言的格式化、解析、自動辨識與 round-trip 驗證；正式 UI
只輸出 `named`，另兩種方言保留作為樣本回歸與相容性檢查。
