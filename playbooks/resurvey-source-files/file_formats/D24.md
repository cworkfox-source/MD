# .D24 註記資料檔

## 用途

註記文字資料（道路名稱等）。《簡介》（2003）將其標為留作擴充用之「道路名稱註記資料檔」；
《使用手冊Win1》已列為一般「註記資料檔」並有讀取功能。

## 已知行為

- 編圖環境「編輯／讀取註記檔」：若目錄下有 `$$####.D24`，跳出「註記資料」對話框，
  選取註記後設定字高、字寬、水平間距（負值＝水平由右向左、垂直由上向下），再點選註記位置。

## 內容格式

手冊未記載內部格式。
