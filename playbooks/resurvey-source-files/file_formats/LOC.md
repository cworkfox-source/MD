# .LOC 宗地圖幅位置報表檔

## 用途

宗地圖幅位置表之輸出檔（每筆宗地位於哪些圖幅）。

## 已知行為

- 「報表、輸出／宗地圖幅位置表／舊地號順、新地號順」產生，寫入 `$$####.LOC`（覆蓋既有檔），可選擇以記事本開啟。
- 舊地號順與新地號順共用同一檔名（後產生者覆蓋前者）。

## 內容格式

報表版面（欄位配置）手冊未載；為人可讀之文字報表。
