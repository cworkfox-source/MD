# .BUN

## ⚠ 同一副檔名有兩種身分（手冊均有記載）

1. **舊版重測資料處理系統二進位檔**（與 .PUN/.COT 並列）：內部格式未載明。
   「報表、輸出／協助指界檔」功能會輸出 `.PUN/.BUN/.COT`。
2. **圖解地籍圖數值化成果管理系統輸入檔**（與 .PUN/.CUN 並列）：
   格式與複丈系統整合版輸入檔相同，即 .BUN ＝ 整合版 .BNP（地號界址檔）格式，
   欄位定義見 [BNP.md](BNP.md) 之整合版格式。

## 判別建議

同 [PUN.md](PUN.md)：先確認檔案來源系統再決定解析方式。
