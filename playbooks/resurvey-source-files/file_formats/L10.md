# .L10 面積計算表

## 用途

清冊列印環境（NECPRINT）輸出之**面積計算表**檔。

## 已知行為（清冊共通規則，見 §601/§602）

- 清冊列印需密碼；無密碼或密碼錯誤僅能列印**一覽表**（兩者表頭不同、內容大致相同）。
- 調查情形 5（糾紛協調）、6（法院訴訟中）、9（地籍誤謬）者：清冊之重測後面積印「未確定」；一覽表印面積但加註調查情形。
- 可指定列印起始頁/終止頁，輸出至檔案或裝置。

## 內容格式

報表版面手冊未載；為編頁之人可讀文字報表。
