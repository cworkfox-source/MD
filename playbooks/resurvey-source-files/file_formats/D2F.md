# .D2F 縮製地籍圖編圖檔

## 用途

縮製地籍圖之編圖檔。**注意**：本副檔名僅見於《使用手冊Win1》§501 之編圖檔命名表，
未列於 §203 之檔案附加名定義清單（該清單止於 .D2D）。

## 檔名規則

同 [D26.md](D26.md)：`$$????##.D2F`，`##` 為二位十六進制圖幅號。

## 已知行為（縮製地籍圖之產生要點）

- 產生方式與 60x80 地籍圖相同，僅於產生編圖檔時選取「縮製地籍圖」。
- 產生前須在「地籍圖繪製設定」將比例尺設定為**地籍圖比例尺之五分之一**，並重新建立 60x80 圖廓。
- 繪圖檔輸出：`$$****_M.###`（見 [PLOT.md](PLOT.md)）。

## 內容格式

實體儲存格式手冊未載；外部程式不應直接讀寫。
