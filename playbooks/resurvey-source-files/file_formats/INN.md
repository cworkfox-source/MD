# .INN 新舊地號對照檔（重測系統輸入檔）

## 用途

重測前（原地號）與重測後（新地號）之地號對照交換檔。

## 內容格式（手冊有載）

資料記錄：

| 順序 | 資料名稱 | 格式 | 說明 |
| ---: | --- | --- | --- |
| 1 | 原地號母號 | I4 | |
| 2 | 空白 | A1 | |
| 3 | 原地號子號 | I4 | |
| 4 | 原段號 | I4 | |
| 5 | 空白 | A1 | |
| 6 | 原地號母號（見疑義） | I4 | |
| 7 | 原地號子號（見疑義） | I4 | |

## ⚠ 疑義：第 6、7 欄欄名

手冊格式表第 6、7 欄之欄名亦寫作「原地號母號／原地號子號」，但本檔為**新舊地號對照**檔，
依用途推測第 6、7 欄應為**新地號母號／新地號子號**（手冊欄名疑為誤植）。實作解析時請以實際資料驗證。
