# .BNI 地號界址檔（重測系統輸入檔）

> 本專案讀取位置：`legacy_import.parse_bni()`（僅當目錄無 D14／D2C／D2B 時觸發）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

重測系統之地號界址交換檔，記錄每筆宗地四周界址點之點號序列，與 .PTM/.CNT/.INN 合為一組重測輸入檔。

## ⚠ 疑義：.BNI 與 .BNP 名稱

手冊功能說明（產生/讀取重測輸入檔）一律使用 **.BNI**；但附錄格式表之標題誤植為「重測系統輸入檔格式:地號界址檔 **(.BNP)**」。
兩者欄位配置與複丈系統ⅠⅡ版之 .BNP 相同，判定該格式表即為 .BNI 之格式。實作時檔名應以 **.BNI** 為準。

## 內容格式（手冊有載）

資料記錄：

| 順序 | 資料名稱 | 格式 | 說明 |
| ---: | --- | --- | --- |
| 1 | 原地號母號 | I4 | |
| 2 | 原地號子號 | I4 | |
| 3 | 原段號 | I4 | |
| 4 | 序號 | I3 | |
| 5 | 圓弧 | I2 | |
| 6 | 地中地 | I2 | |
| 7 | 界址點數 | I4 | |
| 8 | 第 1 點圓弧碼 | A1 | |
| 9 | 第 1 點界址點號 | I4 | |
| 10 | 第 2 點圓弧碼 | A1 | |
| 11 | 第 2 點界址點號 | I4 | |
| … | …（重複至第 11 點） | A1 + I4 | |
| 28 | 第 11 點圓弧碼 | A1 | |
| 29 | 第 11 點界址點號 | I4 | |

- 每一記錄最多容納 11 組（圓弧碼＋界址點號）。
- 界址點數超過 11 點時，依「序號」欄接續多筆記錄（**推測**：格式表列有序號欄且每錄僅 11 點，手冊未明文說明接續規則）。
- 圓弧中點在系統內以點號前綴 `Y` 或負點號表示；圓弧碼欄即對應此標記（A1）。

## 點號位數

- 「讀取（4 位）／（5 位）」：.BNI 點號可為四位數或五位數（5 位版之點號欄寬推定為 I5，手冊格式表僅載 4 位版之 I4）。

## 產生/讀取功能

同 [PTM.md](PTM.md)：「資料輸出、入／重測輸入檔／產生、讀取」，及「舊地籍圖資料／讀取」（舊圖模式）。

## 重建版實測（ADR-040）

`test_datasets/BA0338/BA0338.BNI` 逐位元組驗證，為 **5 位版**：

| 位元組 | 寬度 | 欄位 |
| --- | --- | --- |
| `[0:4]` `[4:8]` `[8:12]` | I4×3 | 原地號母號／子號／原段號 |
| `[12:15]` | I3 | 序號 |
| `[15:17]` `[17:19]` | I2×2 | 圓弧／地中地 |
| `[19:23]` | I4 | 界址點數 |
| `[23:]` | A1+I5 ×11 | 圓弧碼＋界址點號 |

即手冊推定的「5 位版點號欄寬為 I5」獲得樣本證實（每組 6 bytes，非 4 位版的 5 bytes）。
1,323 筆宗地全部解得封閉環，0 筆未解析。

重建版依 A1+I4/I5 固定欄位解析，並以每錄宣告點數在 I4/I5 候選間校驗，因此能保留第一組圓弧碼及每個弧中點位置；圓弧寫法見 [BNP.md](BNP.md) 的實測說明。弧中點會參與 ADR-075 的解析式真弧面積。

`BA0338.CNT`（11,603 點）同樣逐點等於該段 D14（最大差 0.5 mm＝F12.3 進位半量），
可見這組重測輸入檔是**現況**匯出成果，不是舊圖；判讀注意事項見 [COA.md](COA.md)。
