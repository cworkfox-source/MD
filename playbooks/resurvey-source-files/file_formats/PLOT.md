# 繪圖檔（$$****_?.###）

## 用途

編圖環境由編圖檔產生之繪圖機輸出檔，供「列印繪圖檔」以繪圖設備輸出。

## 命名規則（手冊有載）

主檔名＝段代碼＋底線＋圖種代碼；副檔名＝圖幅號：

| 圖種 | 檔名 |
| --- | --- |
| 一覽圖 30x40 規格 | `$$****_A.001` |
| 一覽圖 60x80 規格 | `$$****_A.002` |
| 圖籍 30x40 規格 | `$$****_S.###` |
| 圖籍 60x80 規格 | `$$****_P.###` |
| 圖籍 40x50 規格 | `$$****_E.###` |
| 縮製地籍圖 | `$$****_M.###` |

（`###`＝圖幅號；編圖檔圖幅編號採十六進制擴充，見 [README.md](README.md) 共通慣例 5。）

## 已知行為

- 檔名由系統自動設定，無法更改。
- 繪圖機種類及繪圖原點在產生繪圖檔時已設定；輸出裝置需支援產生時選取之繪圖機種類。
- 「批次產生」需工作目錄中有相對應類型之編圖檔。

## 內容格式

繪圖機指令內容（如 HP-GL 等）依產生時選取之繪圖機種類而定，手冊未載明支援之指令語言清單。
