# .UPN 段別屬性/標記檔

## 用途

用於記錄重測段的基本系統標記或版別屬性資訊。

## 內容格式（依實際檔案分析）

本檔案通常僅包含單行（第一錄）標記，無其他資料記錄。

### 標題記錄（第一錄）

| 欄位格式碼 | 資料名稱 | 常用內容與含意 |
| --- | --- | --- |
| A10 或 A12 | 系統版別/事務所段屬性標記 | 依段別屬性不同，有以下幾種固定標記：<br>1. `BAB0000000` (最常見，約佔 90%)<br>2. `BAB020000000`<br>3. `BAB030000000`<br>4. `BAB040000000` |

*註：字串由 `地政事務所代碼` (如 `BA`) + `B` + `版別代碼` (如 `00`, `02`, `03`, `04`) + `填零` 組成。*
