# .A10 面積調整報表

## 用途

「線段、面積／面積調整」及「截彎取直」執行完成後產生之調整結果報表。

## 已知行為

- 主檔名為執行日期（年月日）。
- 面積調整之界址線平移距離須在可移動最大範圍內（系統預設 0.35 m；市地建議用預設值，農地/山地可放大至一至數公尺）。

## 內容格式

報表版面手冊未載；為人可讀之文字報表。
