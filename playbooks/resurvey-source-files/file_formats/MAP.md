# .MAP 圖幅索引檔（複丈系統整合版）

## 用途

複丈系統整合版之地籍圖／公告圖圖幅索引交換檔。

## 內容格式（手冊有載，僅整合版）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 縱方格數 | I3 |
| 橫方格數 | I3 |
| 段圖幅左下角縱坐標 | F11.3 |
| 段圖幅左下角橫坐標 | F10.3 |

### 資料記錄（其他錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地籍圖圖號 | I3 |
| 公告圖圖號 | I3 |
| 圖幅左下角縱坐標 | F11.3 |
| 圖幅左下角橫坐標 | F10.3 |
| 圖幅右下角縱坐標 | F11.3 |
| 圖幅右下角橫坐標 | F10.3 |

## 相關

- 系統內部之圖幅號索引為 .D22（格式未公開），見 [D22.md](D22.md)。
