# .D2A 40x50cm 圖編圖檔

## 用途

40x50 cm 圖之編圖檔（每圖幅一檔）。

## 檔名規則

同 [D26.md](D26.md)：`$$????##.D2A`，`##` 為二位十六進制圖幅號（最大 575 幅）。

## 已知行為

- 「其他工具／產生編圖檔／40x50 編圖檔」產生。

## 內容格式

實體儲存格式手冊未載；外部程式不應直接讀寫。
