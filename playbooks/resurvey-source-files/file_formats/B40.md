# .B40 交點計算結果報表

## 用途

「界址計算／交點計算」與「平移求交點」之計算結果報表（共用本副檔名）。

## 已知行為

- 主檔名為系統日期之年月日。
- 線段可為既有直線/圓弧，或臨時以兩點（直線）/三點（圓弧）組成。
