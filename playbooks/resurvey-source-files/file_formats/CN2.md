# .CN2 街廓連線資料檔

## 用途

都市計劃樁清理補建系統產生之**街廓連線資料**，與 .CN1（中心樁連線）、.CN3（街廓坐標）成組轉入重測系統。

## 已知行為（讀入規則）

同 [CN1.md](CN1.md)：任選一檔即可整組讀入；街廓點存為 `.98` 參考點、連線存至參考線第 9 層。

## 內容格式

手冊未記載欄位格式；需向都市計畫樁清理補建系統文件查證。
