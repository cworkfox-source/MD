# .B20 道路截角計算結果報表

## 用途

下列「界址計算」功能之計算結果報表（共用本副檔名）：

- 直線截角（CHAMFER）：四個直線截角、八組坐標
- 圓弧截角（FILLET）：四個圓弧截角、十二組坐標（每弧三點）
- 單直線截角（CHAMFER1）：一個截角、二組坐標
- 單圓弧截角（FILLET1）：一個截角、三組坐標
- 道路外截角（OFFILET）：二個圓弧外截角、六組坐標
- 道路路邊線：直線道路四組、圓弧道路六組坐標

## 已知行為

- 主檔名為系統日期之年月日。
- 路寬 6 m 以下時截角長度顯示 0，除非自行輸入。
- 截角線段之端點若均有存檔點號，線段自動建立。
