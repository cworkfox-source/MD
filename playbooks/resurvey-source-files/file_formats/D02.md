# .D02 控制點資料檔

## 用途

存放測區共用之控制點（圖根點、中心樁）資料，位於 `\NECSYS` 目錄。

## 已知行為

- 控制點資料異動時，須經「資料檔輸入、出／控制測量輸入檔／讀取」（.CTL/.CEN）更新，
  「建修查檔／測區控制點」僅提供瀏覽。

## 內容格式

手冊未記載內部格式；外部程式不應直接讀寫，控制點交換請使用 [.CTL](CTL.md)/[.CEN](CEN.md)。
