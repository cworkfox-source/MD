# .D11 宗地資料檔

## 用途

記錄每一宗土地之基本資料。與地籍調查系統**共用**宗地資料（原則上由地籍調查系統建立維護）。

## 內容格式（依實際檔案分析，已用兩個獨立段樣本交叉驗證）

本檔案為標準 **dBASE III (.dbf) 資料庫**。欄位結構（名稱/型態/寬度/順序）已分別於 `BA0002.D11`
（3506 筆）與 `PP0001.D11`（3506 筆，1150623修版）兩個**互不相關的重測段樣本**中獨立驗證一致，可信度高。

### 檔案整體結構

- 第 1 段：DBF 檔頭（版本、日期、資料筆數、檔頭長度、每筆資料長度）。
- 第 2 段：欄位描述區，每個欄位描述固定 32 bytes。
- 第 3 段：欄位描述結束符號 `0x0D`。
- 第 4 段：資料區，每筆資料固定長度，第 0 byte 為刪除旗標（空白＝正常、`*`＝已刪除應略過）。

### 檔頭欄位（dBASE 標準）

| Byte 位置 | 長度 | 說明 |
| --- | ---: | --- |
| 0 | 1 | DBF 版本，`0x03`＝dBase III 類型 |
| 1–3 | 3 | 最後更新日期（年/月/日）；本系統此區塊不符合標準 `年-1900` 慣例，不建議用於判斷實際異動時間 |
| 4–7 | 4 | 資料筆數（小端序 unsigned int） |
| 8–9 | 2 | 檔頭長度（小端序 unsigned short） |
| 10–11 | 2 | 每筆資料長度（小端序 unsigned short） |
| 32 起 | 每欄 32 | 欄位描述區，每欄名稱（0–10，NUL 結尾）＋型態（11）＋長度（16）＋小數位數（17），直到遇 `0x0D` |

### 驗證與疑義

- 前 20 個欄位（`PAR_O_M` ~ `LIMIT`）之語意可直接對應手冊「宗地資料」編輯畫面與 `_codes.md` 代碼表，且欄位配置與起始位置已在 BA0002、PP0001 兩個獨立段樣本中一致確認，信心度高。
- 第 21 欄以後（`DIV_MER`、`TABLE_NM`、`TABLE_NC`、`REST_C`、`REST_D`、`GROUP_S`、`GROUP_E`、`INVES_17` 等）為手冊未直接說明之欄位，語意依欄位名稱與鄰近欄位脈絡推測，**尚未有實際資料值逐一交叉驗證**。
- `CATE_OLD`/`CATE_NEW`（地目）長度僅 1 碼，說明地目以單一代碼字元儲存（對照複丈整合版 .PAR 格式亦為 `A1`）。
- `AREA_NEW`（重測後面積，單位公頃）可與 [D13](D13.md)＋[D14](D14.md) 依界址點坐標以 shoelace 公式重建之宗地多邊形面積互相驗證：`polygon 面積(平方公尺) ≈ AREA_NEW × 10000`，詳見 [D13.md](D13.md)「與 D14 合併重建宗地圖形」一節。

## 已知行為

- 「建修查檔／宗地資料」編輯後**立即存檔**。
- 宗地資料總筆數未限制。

## 轉出/剖析建議

- 忽略每筆資料第 0 byte 之刪除旗標，`*` 者不應輸出。
- 數字欄位為右靠、前方補空白；空白數字欄位可轉為空值。
- 欄位值一律使用固定起始位置＋長度擷取，不要僅用空白切割字串。
- 轉出後應驗證：CSV 資料列數＝DBF 正常資料筆數、欄位數＝DBF 欄位數、抽樣前幾筆內容與原始固定欄位一致。

## 相關

## 重建版實測（ADR-043）

本檔是**段內**的面積來源，不需任何交換檔即可供給舊圖面積比對：

| 欄位 | 用途 | key | 單位 |
| --- | --- | --- | --- |
| `AREA_OLD` | 原登記面積 | 原地號 (`SECTION_O`,`PAR_O_M`,`PAR_O_C`) | 公頃（×10000 得平方公尺） |
| `AREA_NEW` | 重測後面積 | 新地號 (`SECTION_N`,`PAR_N_M`,`PAR_N_C`) | 公頃 |
| `AREA_DIG` | **原版自己算的數化面積** | 原地號 | 公頃 |

`BA0002` 完全沒有 `.PAR`／`.PTM`，卻有 **3,498 筆 `AREA_OLD`**，因此重建版把
`.D11` 列為登記面積的最高權威來源（順序為 `.PTM` → `.PAR` → `.D11`）——D11 是可由
「建修查檔／宗地資料」就地編輯的活表。

### `AREA_DIG` 作為數化面積的驗證基準

`AREA_DIG` 由原版「舊地籍圖資料／讀取」時自動置入，是原版對同一批舊圖宗地環算出的
數化面積。重建版以 D2B 環的 shoelace 面積與其比對：

| 樣本 | 筆數 | 中位誤差 | 0.1% 內 |
| --- | ---: | ---: | ---: |
| BA0002 | 3,498 | 0.0037% | 95.8% |
| BA0762 | 738 | 0.0044% | 95.4% |

殘差來自 `AREA_DIG` 以公頃六位小數儲存（量化 0.01 m²）與圓弧以弦近似。
重建版仍以自身 shoelace 為顯示值（`AREA_DIG` 只在原版曾執行過舊圖讀取的段才有值，
交換檔疊圖段一律沒有），`AREA_DIG` 另存於 `ParcelAreaFacts.recorded_digitized` 供交叉驗證。

`SCALE`／`OLDSCALE` 見 [D10.md](D10.md)：BA0338／BA0762 實測為 500／600，
但 BA0002、DD2138 之 D10 全欄空白，故比例尺另提供逐段手動設定。
