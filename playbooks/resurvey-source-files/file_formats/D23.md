# .D23 區段界資料檔

## 用途

儲存段界（區段界）點坐標與區段界形式，供產生編圖檔時繪製段界使用。

## 內容格式（手冊有載）

ASCII 文字檔，每一列描述一點之坐標及區段界形式，各資料間以**空白、逗號或 TAB（擇一即可）**隔開：

```
[A] NUM Y X [MODE]
```

| 欄位 | 說明 |
| --- | --- |
| `A` | 是否為圓弧（可不輸入） |
| `NUM` | 自動給定之點號（可任意給） |
| `Y` | 區段界點坐標 Y（縱） |
| `X` | 區段界點坐標 X（橫） |
| `MODE` | 此點至下一點之區段界形式；不填表沿用上一行設定：1＝小段界、2＝段界、3＝鄉鎮市區界、4＝縣(市)界、5＝省(市)界 |

- **不同區段界（不連續之線串）之間，以空白列隔開。**

## 範例（取自手冊）

A–D 為段界，B–E–F–C 為小段界：

```
Ay  Ax  2      ← A 點坐標，線型指定為 2（段界）
Dy  Dx         ← D 點坐標（沿用上行線型）
               ← 空白列，表上一段界線串結束
By  Bx  1      ← B 點坐標，線型指定為 1（小段界）
Ey  Ex
Fy  Fx
Cy  Cx
```

## 產生/讀取功能

- 「其他工具／段界產生／產生段界」：自動計算段外圍後存入本檔。輸入「段界擴張量（預設 1 公尺）」與「線段約化角度（預設 2.0）」；段界點自 1 起循序編號。
- 「其他工具／段界產生／編修段界、區段界設定、新增段界線」：圖形介面編修。
- 「其他工具／段界產生／文字編修段界」：直接以記事本開啟本檔編輯。
- 「其他工具／產生編圖檔」時使用本檔資料。

## 注意事項

- 產生段界前應先執行「資料整理／重測成果檢核」確認段界無誤。
- 線段約化角度過大易使段外圍變形，過小則約化效果不佳。
