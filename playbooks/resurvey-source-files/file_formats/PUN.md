# .PUN

## ⚠ 同一副檔名有兩種身分（手冊均有記載）

1. **舊版重測資料處理系統二進位檔**（與 .BUN/.COT 並列）：內部格式未載明。
   「報表、輸出／協助指界檔」功能會輸出 `.PUN/.BUN/.COT`。
2. **圖解地籍圖數值化成果管理系統輸入檔**（與 .BUN/.CUN 並列）：
   手冊明載「其格式和複丈系統整合版輸入檔相同」，即 .PUN ＝ 整合版 .PAR（宗地資料檔）格式，
   欄位定義見 [PAR.md](PAR.md) 之整合版格式。

## 判別建議

解析前應先確認檔案來源系統；若為圖解數化成果管理系統產出，依整合版 .PAR 格式（文字檔）解析；
若為舊版重測系統產出之二進位檔，格式未公開，不應直接讀寫。
