# .B15 分段合併點號變更對照表

## 用途

「其他工具／資料合併（分段合併）」時，被合併段之確定點/參考點點號經自動調整後，
點號變更對照表存於本檔。

## 已知行為（點號調整規則，手冊有載）

- 第一個合併資料段之點號保持不變。
- 其後加入之工作段點號，以合併後資料段之最大點號加 1 自動調整；參考點跟隨確定點點號調整。
- 加入之確定點坐標已存在者，後加入之點號自動滅失。
- 點號及坐標皆與原合併段不同者，點號不變動。
