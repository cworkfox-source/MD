# .D27 30x40cm 圖編圖檔

## 用途

30x40 cm 圖（公告圖）之編圖檔（每圖幅一檔）。

## 檔名規則

同 [D26.md](D26.md)：`$$????##.D27`，`##` 為二位十六進制圖幅號（最大 575 幅）。

## 已知行為

- 「其他工具／產生編圖檔／30x40 編圖檔」產生。
- 產生時若同比例尺之對應 60x80 圖存在，自動引用其地號、中文註記位置（點號/點名採相對位置引用；地籍經界線不引用）。

## 內容格式

實體儲存格式手冊未載；外部程式不應直接讀寫。
