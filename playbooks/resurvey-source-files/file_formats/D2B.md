# .D2B 舊地籍圖地號界址檔

## 用途

數化舊地籍圖之地號界址資料層（舊地籍圖僅供背景圖顯示，舊圖點可被引用）。本檔案記錄舊地籍圖中地號與界址點序列的對應關係。

## 已知行為

- 「資料輸出、入／舊地籍圖資料／讀取（4 位）、（5 位）」將 .PTM/.BNI/.CNT 以舊圖模式讀入本資料層。
- 「舊地籍圖資料／刪除」刪除舊地籍圖資料檔。
- 相關作業：三參數轉換套圖、人工微調、引用舊圖點。

## 內容格式（依實際檔案分析）

本檔案為標準 **dBASE III 資料庫檔案 (.dbf)**。

## 重建版實測（ADR-041）

本檔 19 個欄位中**沒有面積欄位**（只有舊段號、舊地號母／子與 8 組「弧標記＋點號」）。
因此舊圖宗地的「數化面積」只能由本檔還原出的宗地環計算，不能讀取；直線邊採 shoelace，`MIDARC_n = T` 的三點弧採解析式圓弧段修正（ADR-075）；
可供比對的「登記面積」須另取自 [.PAR](PAR.md) 或 [.PTM](PTM.md)，並以**原地號**
(`O_SECTION`, `O_PARCEL`, `O_PARCEL_E`) 對接。

`MIDARC_n` 為 L (Logical) 型弧標記，與交換檔 .BNP/.BNI 的「點號後綴 `+`／`-`」
是同一件事的兩種表示法，見 [BNP.md](BNP.md)。

BA0762 的 10 宗／14 個 D2B 弧中點與 AM0009 的 14 宗／20 個弧中點實測：採真弧後全部與原版 D11 `AREA_DIG` 相差不超過 0.01 m²；只算兩段弦時最大誤差分別為 120.91 m² 與 0.97 m²。
