# .D26 60x80cm 圖編圖檔

## 用途

60x80 cm 地籍圖之編圖檔（每圖幅一檔），供編圖環境編輯註記後產生繪圖檔。

## 檔名規則（手冊有載）

`$$????##.D26`：`$$????`＝重測段代碼、`##`＝第幾幅圖（二位十六進制：01~FF＝1~255；十位擴充 0~Z、個位 0~F，ZF＝575 幅為最大值）。

## 已知行為

- 「其他工具／產生編圖檔／60x80 編圖檔」產生；產生前須設定比例尺（地籍圖繪製設定）並建立段界檔（.D23）。
- 重複產生同一幅圖時自動引用相關註記位置；產生 30x40 圖時若同比例尺之 60x80 圖存在，自動引用其註記位置。
- 編圖檔與重測資料為獨立資料，原資料異動後須重新產生編圖檔。
