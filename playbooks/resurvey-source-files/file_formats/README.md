本資料夾為「地籍圖重測資料處理系統（視窗版）」所有已知副檔名的格式基準參考資料，
供後續程式開發時查閱。**每個副檔名一份 MD 檔**，內容完全取自下列轉寫文件，未載明處一律標註，不做臆造：

- `docs/doc_transcripts/視窗版重測系統使用手冊1.md`（使用手冊前半）

## frontmatter 欄位說明

| 欄位 | 意義 |
| --- | --- |
| `extension` | 副檔名（含點） |
| `name` | 手冊所載檔案名稱 |
| `category` | 分類（見下方索引分組） |
| `file_pattern` | 檔名命名規則 |
| `data_type` | 文字 / 二進位 / 報表等 |
| `format_spec` | `full`＝手冊有完整欄位格式；`partial`＝僅部分格式或行為可知；`none`＝僅知用途，內部格式未載明 |

## 共通慣例

1. **段代碼 `$$####`**：`$$`＝兩位英文字母之地政事務所代碼，`####`＝四位數字段代碼（不足補 0），如 `AA0005`。重測段目錄即以段代碼命名。
2. **坐標順序**：本系統一律「縱坐標（Y）在前、橫坐標（X）在後」。
3. **點號體系**：界址點（確定點）1~99999；每一確定點可有 99 個參考點，以小數表示（如 `100.23`＝點 100 之第 23 參考點）；`.98` 保留給街廓點；私有補點點名以 `Q` 開頭；控制點以點名（如 `IP101`）表示。
4. **欄位格式碼**（交換檔格式表所用，FORTRAN 慣用描述符）：
   - `In`＝n 位整數（如 `I4`）
   - `An`＝n 個字元之文字（如 `A2`）
   - `Fw.d`＝總寬 w、小數 d 位之定點數（如 `F12.3`）
   - 交換檔為固定欄寬之循序文字檔；「標題記錄（第一錄）」為檔頭，「資料記錄（其他錄）」為資料本體。
5. **圖幅編號（十六進制擴充）**：編圖檔主檔名 `$$????##` 之 `##` 採二位十六進制，`01`~`FF` 表 1~255 幅；十位數擴充至 `0`~`Z`、個位 `0`~`F`，故 `G0`=256、`H0`=272、`Z0`=560、`ZF`=575（最大 575 幅）。
6. **計算報表檔（.A10 / .B10~.B90）**：主檔名為系統日期之「年月日」，副檔名區分報表種類。
7. 交換用文字檔各筆資料間，部分格式（如 .D23、.MAC）允許以空白、逗號或 TAB 分隔；固定欄寬格式（.PTM 等）則依格式碼欄寬。
8. 相關代碼表（調查情形、公私有、使用情形、經界物代碼等）集中於 [_codes.md](_codes.md)。
9. **段內部 `.D1x`／`.D2x` 資料檔實測為 dBASE III (.dbf) 資料庫**（依 BA0002 樣本段實際檔案逆向確認），可用任何標準 dBASE/dbf 函式庫讀取；唯一例外是 `.D25`（測量資料記錄檔），其為系統自訂的 79 位元組固定長度二進位記錄，非 dBASE 格式。

## 使用注意

- `format_spec: none` 之檔案為系統內部二進位或未公開格式，**外部程式不應嘗試直接讀寫**，應透過系統「資料輸出、入」功能轉成交換格式（.PTM/.BNI/.CNT/.INN 或 .PAR/.BNP/.COA/.RCO）。
- 手冊間有少數不一致處（.DRW/.DW、.BNI/.BNP、.INN 欄名），均已於各檔「疑義」小節記錄，引用時請注意。
