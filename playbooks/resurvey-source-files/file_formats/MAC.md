# .MAC 測量資料文字檔

## 用途

外業測量觀測資料之文字輸入檔，供「資料輸出、入／批次計算」批次執行光線法與直線截點計算；
亦為「產生測量文字檔」功能將測量資料記錄檔（.D25）轉出之格式（重算時用文字編輯器保留欲重算部分）。

## 內容格式（手冊有載）

由計算區塊組成，每區塊以前導命令列開頭。原版動態相容性限制見「注意事項」。

### 光線法區塊

```
LS                                ← 光線法計算前導命令
測站點  標定點
觀測點[(註記)]  右旋角  平距          ← 無天頂距之觀測列
觀測點[(註記)]  右旋角  天頂距  斜距   ← 有天頂距之觀測列
...（觀測列重複）
```

### 直線截點區塊

```
LB                                ← 直線截點計算前導命令
已知點一  已知點二
第一段距離  存檔的點號
第二段距離  存檔的點號
...（各段重複）
最後段距離                          ← 最後一段僅距離、無點號
```

### 通則（手冊註記）

1. 各輸入格間只要有**一個以上空白**隔開即可。
2. 各點號或點名直接鍵入，**不需前導碼（`*`）**。
3. 角度格式為 `xxx.xxxx`（**度.分秒**），例：12 度 23 分 45 秒輸入 `12.2345`。重建版產生檔固定補齊 4 位分秒；原版既有數值格式檔可能省略尾端 0（`293.191` 代表 `293.1910`），重建版讀取時會向右補零。
4. 光線法觀測點可附備註資料，如 `100(3+)` 表觀測點號 100、註記資料 `3+`（經界物代碼，見 [_codes.md](_codes.md)）；**註記資料不得含空格或逗號**。

## 產生/讀取功能

- 「資料輸出、入／批次計算」：讀取 .MAC 或 .RAW；可選擇是否將觀測資料記錄至 .D25、是否啟動重複界址點坐標存檔警告。
- 「資料輸出、入／產生測量文字檔」：將 `$$####.D25` 轉出至 `$$####.MAC`。

## 注意事項

- 僅處理右旋度盤經緯儀之觀測資料。
- 觀測點可為私有補點（點名 Q 開頭），補點資料將建立於私有補點檔（.D20）。
- **同一檔不得重複 `LS`**：15 份 BA0528 實檔每檔最多一個 `LS`；2026-07-29 原版 P0 測試在第二個 `LS` 後的測站／後視列報 `MACRO` 錯誤。需要切換測站時，直接在同一 LS 區塊中插入新的二欄「測站 後視」列，再接該站觀測列；使用者已確認此多測站合併語法。`LB` 與 `LS` 混合或重複 `LB` 尚未動態驗證，不據此推論。
