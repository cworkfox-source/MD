# .DRW / .DW 繪圖參數檔

## 用途

各重測段目錄下之繪圖參數檔；手冊註明**可刪除**（系統可重建）。

## ⚠ 疑義：副檔名不一致

- 《簡介》（2003）之附檔名定義列為 **.DRW**。
- 《重測系統使用手冊Win1》之附檔名定義列為 **.DW**。

兩者指同一「繪圖參數檔（可刪除）」，實際副檔名請以現場檔案為準。

## 內容格式

手冊未記載內部格式；外部程式不應依賴此檔。
