# .CUN 圖解數化界址坐標檔

## 用途

圖解地籍圖數值化成果管理系統之界址坐標輸入檔（與 .PUN/.BUN 並列成組）。

## 內容格式

手冊明載「其格式和複丈系統整合版輸入檔相同」，即 .CUN ＝ 整合版 .COA（界址坐標檔）格式，
欄位定義見 [COA.md](COA.md) 之整合版格式。
