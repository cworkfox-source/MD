# .BNP 地號界址檔（複丈系統輸入檔）

> 本專案讀取位置：`legacy_import.parse_bnp()`（僅當目錄無 D14／D2C／D2B 且無 .BNI 時觸發）。完整流程見 `docs/legacy_import_file_map.md`。


## 用途

複丈系統之地號界址交換檔（每筆宗地四周界址點之點號序列）。**同一副檔名有兩種版本格式**。
圖解地籍圖數值化成果管理系統之 .BUN 與整合版 .BNP 格式相同。

## 格式一：複丈系統ⅠⅡ版（手冊有載）

無標題記錄之記載。資料記錄：

| 順序 | 資料名稱 | 格式 |
| ---: | --- | --- |
| 1 | 原地號母號 | I4 |
| 2 | 原地號子號 | I4 |
| 3 | 原段號 | I4 |
| 4 | 序號 | I3 |
| 5 | 圓弧 | I2 |
| 6 | 地中地 | I2 |
| 7 | 界址點數 | I4 |
| 8~29 | 第 1~11 點：圓弧碼 A1 ＋ 界址點號 I4（重複 11 組） | |

## 格式二：複丈系統整合版（手冊有載）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 資料錄筆數 | I5 |

### 資料記錄（其他錄）

| 順序 | 資料名稱 | 格式 |
| ---: | --- | --- |
| 1 | 新地號母號 | I4 |
| 2 | 新地號子號 | I4 |
| 3 | 序號 | I3 |
| 4 | 界址點數 | I4 |
| 5~26 | 第 1~11 點：圓弧碼 A1 ＋ 界址點號 **I5**（重複 11 組） | |

## 版本差異速記

| 項目 | ⅠⅡ版 | 整合版 |
| --- | --- | --- |
| 地號 | 原地號（母/子/原段號） | 新地號（母/子） |
| 標題記錄 | 未載 | 有 |
| 界址點號欄寬 | I4 | I5 |
| 圓弧/地中地旗標欄 | 有 | 無 |

## 附註

- 每一記錄最多 11 組（圓弧碼＋界址點號）；界址點數超過 11 點時依「序號」欄接續多筆記錄（**推測**，手冊未明文說明接續規則）。
- 重測系統輸入檔之 .BNI 採用與ⅠⅡ版 .BNP 相同之欄位配置（手冊格式表標題誤植），見 [BNI.md](BNI.md)。

## 重建版實測（ADR-040）

以 `test_datasets/DD2138.BNP`（1,359 筆）與 `BA0762.BNP`（714 筆）逐位元組驗證，
兩者**皆為整合版**：標題錄 `A2+I4+I5`；資料錄 `I4 母 / I4 子 / I3 序號 / I4 界址點數`，
之後為最多 11 組「圓弧碼＋點號」，實測欄寬為 **I5**（每組 6 bytes）。

### ⚠ 圓弧標記與手冊欄位表不符

手冊列為「圓弧碼 A1 ＋ 界址點號 I4」（碼在**前**），但實體樣本的圓弧是點號的
**後綴** `+` 或 `-`：

```
09940000  1   5  2102  2103  2094+ 3039  2093
```

即「由 2094 起，經弧中點 3039，連到下一角點 2093」。此寫法與
[BNP_COA_PAR_讀取說明與Agent_Skill.md](BNP_COA_PAR_讀取說明與Agent_Skill.md) 描述的
`A+B` 記法一致，只是固定欄寬把兩個點號拆進相鄰欄位。

按手冊的前置解讀會使 `2094+` 整個 token 比對失敗而**丟棄該角點**：修正前 BA0762
面積符合率 91.9%／p95 誤差 16.29%，修正後 99.0%／0.12%。

弧中點被計入「界址點數」，故它是真實界址點；重建版保留為頂點，畫面仍可用兩段弦，面積則以相鄰三點的解析式真弧計算，不以渲染折線插值（ADR-075）。固定欄位解析亦保留第一組獨立 `+`／`-`；BA0762 共辨識 64 宗、124 個弧中點，全部與 `.PAR` 面積相差不超過 0.01 m²。

### 續錄與 join key

同一 (母, 子) 的多筆記錄依「序號」由小到大接續（DD2138 有 24 點分 3 錄的實例）。
與 .PAR 對接時，整合版 BNP 以**新地號**編 key，須取 PAR 的 `[22:26]/[26:30]`
（新地號），不是 `[0:4]/[4:8]`（原地號）——BA0338 原 13-1 對新 238-0，取錯即完全接不起來。

複丈ⅠⅡ版版面在 repo 內**無樣本**，重建版僅依手冊實作為後備並標示未驗證。
