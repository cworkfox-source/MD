# .RCO 參考坐標檔（複丈系統輸入檔）

## 用途

複丈系統之參考點坐標交換檔（確定點所屬之參考點）。**同一副檔名有兩種版本格式**。

## 格式一：複丈系統ⅠⅡ版（手冊有載）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 最大記錄數 | I5 |

### 資料記錄（其他錄）

| 資料名稱 | 格式 |
| --- | --- |
| 點號 | I5 |
| 參考點號 | I2 |
| Y 坐標 | F12.3 |
| X 坐標 | F11.3 |

## 格式二：複丈系統整合版（手冊有載）

### 標題記錄（第一錄）

| 資料名稱 | 格式 |
| --- | --- |
| 地政事務所代碼 | A2 |
| 新段號 | I4 |
| 資料錄總數 | I5 |

### 資料記錄（其他錄）

| 資料名稱 | 格式 |
| --- | --- |
| 點號 | I5 |
| 參考點編號 | I2 |
| Y 坐標 | F11.3 |
| X 坐標 | F10.3 |
| 界標種類 | A1 |

## 附註

- 「點號」＝所屬確定點點號；「參考點號（編號）」＝該確定點之第幾參考點（1~99）。
- 整合版多一「界標種類」欄，且坐標欄寬較ⅠⅡ版各少 1 位。
