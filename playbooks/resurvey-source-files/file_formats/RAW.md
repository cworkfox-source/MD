# .RAW 外業自動化觀測資料檔

## 用途

外業自動化（電子測距經緯儀等）觀測資料檔，經「資料輸出、入／批次計算」與 .MAC 同一功能讀入計算。

## 已知行為

- 讀入時可選擇是否將觀測資料記錄至 .D25、是否啟動重複界址點坐標存檔警告。
- 檔案不需位於工作目錄。

## 內容格式

手冊僅記載 .MAC 之格式（見 [MAC.md](MAC.md)），**.RAW 之格式未載明**（推測為儀器原始記錄格式，與 .MAC 不同，否則無需區分兩種副檔名）。
如需解析請以實際資料或儀器文件查證。
