# .D28 段接續一覽圖編圖檔

## 用途

段接續一覽圖之編圖檔。

## 檔名規則（手冊有載）

一覽圖規格：`$$????01.D28`（30x40）、`$$????01.D28`（60x80）——手冊表列兩規格同檔名（圖幅號固定 01）。

## 已知行為

- 「其他工具／產生編圖檔／一覽圖編圖檔」產生。
- 繪圖檔輸出：一覽圖 30x40 → `$$****_A.001`、60x80 → `$$****_A.002`（見 [PLOT.md](PLOT.md)）。

## 內容格式

實體儲存格式手冊未載；外部程式不應直接讀寫。
